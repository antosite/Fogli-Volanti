# Modelli

Questi file **non compaiono nel sito**: sono da copiare.

| Vuoi creare… | Copia | Incollalo in |
|---|---|---|
| un articolo / post | `articolo.md` | `contenuti/cartelle/<categoria>/nome-articolo.md` |
| un episodio del podcast | `episodio-podcast.md` | `contenuti/cartelle/podcast/episodio-03.md` |
| un post con un video | `video.md` | `contenuti/cartelle/video/nome-video.md` |
| una categoria | la cartella `nuova-categoria/` | `contenuti/cartelle/nome-categoria/` |
| una pagina fissa | `pagina.md` | `contenuti/pagine/nome-pagina.md` |

Le righe che iniziano con `#` dentro il blocco tra `---` sono commenti: puoi lasciarle o cancellarle.
Il nome del file diventa l'indirizzo della pagina: usa minuscole e trattini, niente spazi né accenti.
